# ADR-0007: ホスティング先（API・Web アプリ・DB）

- 状態：承認
- 日付：2026-11-15

## 背景

個人利用で、運用費は 0 円に抑えたい。PostgreSQL を素のまま使いたい。

## 選択肢（2026 年 11 月時点の無料枠）

| 対象 | 選択肢 | 良い点 | 気になる点 |
| --- | --- | --- | --- |
| DB | **Neon** | 無期限の無料枠。使わないと自動停止し、計算資源を消費しない | 停止からの初回アクセスが数秒遅い |
| DB | Supabase | 管理画面が充実 | 7 日間アクセスがないと一時停止し、手動で再開が必要 |
| DB | Render | — | 無料の Postgres は 30 日で期限切れ |
| DB | Fly.io | — | 無料枠がない |
| API | **Cloudflare Workers** | カード登録不要。起動が速い。Hono と相性がよい | 1 リクエストあたり CPU 10ms |
| API | Google Cloud Run | 制約が少ない | カード登録が必要。起動に数秒 |
| API | Render | — | 15 分無操作で停止し、復帰に約 1 分 |

## 決定

API と Web アプリは 1 つの Cloudflare Worker から配信し、DB は Neon を Hyperdrive 経由で使う。

## 理由

- すべて無料枠で月 0 円。
- 画面と API を同じオリジンにすると、リフレッシュトークンの Cookie がサードパーティ扱いでブロックされず、CORS も不要になる。

## 影響

- CPU 10ms に収めるため、重い計算（速度の計算）は ESP32 で済ませ、生データはバイナリのまま保存する。
- 足りなくなったら Workers Paid（月 5 ドル）か Cloud Run に移る。Hono なのでコードの変更は少ない。
