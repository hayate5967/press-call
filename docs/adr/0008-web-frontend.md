# ADR-0008: Web アプリのフレームワーク

- 状態：承認
- 日付：2026-11-15

## 背景

画面は Web アプリ 1 つ。ログイン後に自分だけが使う画面で、SEO は不要。API は Hono が担う。

## 選択肢

| 選択肢 | 良い点 | 気になる点 |
| --- | --- | --- |
| Vite＋React（SPA） | 画面の役割だけに集中できる。ビルド結果を Worker に置くだけ | SSR・SEO はない（今回は不要） |
| Next.js | SSR・サーバーコンポーネント | Hono と役割が重なる。Workers で動かすには追加の設定が必要 |

## 決定

Vite＋React の SPA を採用する。見た目は shadcn/ui＋Tailwind CSS、グラフは Recharts。ルーティングは TanStack Router、データ取得は TanStack Query を使う。

## 理由

モダンな見た目は UI ライブラリで決まり、フレームワークでは決まらない。フロントと API を分けて設計したことを説明しやすい。

## 影響

ESP32 が配信するのは初回設定用の小さな設定ページ（素の HTML）だけ。
